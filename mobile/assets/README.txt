Place the following image assets here:
- icon.png          (1024x1024 - app icon)
- splash.png        (1242x2436 - splash screen, dark blue background #1e2b6b)
- adaptive-icon.png (1024x1024 - Android adaptive icon foreground)
- favicon.png       (32x32 - web favicon)

You can use any BA logo or placeholder image.
Expo will warn at build time if these are missing, but the app will still run.
